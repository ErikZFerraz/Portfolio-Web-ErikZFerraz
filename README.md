# Portfolio Web — Erik Zanetti Ferraz

Portfólio profissional desenvolvido em React + TypeScript + Vite + Tailwind CSS, com animações em Framer Motion e apresentação dos principais projetos acadêmicos e profissionais.

## Executar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no terminal.

## Gerar versão de produção

```bash
npm run build
```

A versão final será criada na pasta `dist`.

## Publicação

O projeto está preparado para deploy na Vercel. Conecte o repositório do GitHub à Vercel, mantenha o framework como **Vite** e publique. As configurações padrão detectadas automaticamente são suficientes:

- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Principais tecnologias

React, TypeScript, Tailwind CSS, Framer Motion, Vite e Lucide React.
